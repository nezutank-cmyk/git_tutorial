ステージは次のコミットのファイル状態
git addすることで変更を記録できる。なお、インデックスファイルに記載の内容は次のコミットのファイル状態なので、変更のないファイルの全て記録されている。更新がされるのは変更がaddされたファイルのみだけどね。
git statusは作業場とステージ、ステージとリポジトリで変更されたファイルを調べる
git diff は変更ファイルの何が変更されたかを調べられる

git rmで作業場とリポジトリと両方で削除できる
git rm --cachedでリポジトリからだけ削除できる

git commitはその状態のファイルのスナップショットを記録している。

git におけるoriginのとはリモートのURLのショートカット（デフォルトの）
origin = https://github.com/user/repo.git
なおoriginという名前は慣例的に作られているだけなので自由でOK
